## 在 Mac 的 VS Code 中运行

1. 用“文件 → 打开文件夹”打开 `week4`。终端执行 `clang++ --version` 可以确认编译器可用。
2. 按 `⌘⇧B`，从列表选择“运行”开头的题目。任务会编译该题目录下的全部 `.cpp`，随后在集成终端执行程序。
3. 需要输入时，在集成终端输入数据并回车。报告内附本次实验的终端截图。
4. 单步观察时安装 **CodeLLDB**，在源码中设置断点，在“运行和调试”的下拉菜单选择题目并按 `F5`。例如在“指针 4”的 `swapValues` 调用处停住，用单步越过观察待排序部分的最小元素如何换到当前位置。
