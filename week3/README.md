## 在 VS Code 中运行

1. 使用“文件 → 打开文件夹”打开本 week3 文件夹。
2. 按 `Command+Shift+B`，从列表选择一道题。
3. 程序自动编译运行，无需输入数据。截取终端结果，按题号插入报告相应位置。
4. 依次运行以下六项。不要用只编译当前单个文件的运行按钮；除 5-3、5-13 外，每题需要同时编译类实现和 main。

| 目录 | 内容 |
|---|---|
| 01_static_data | 普通成员与共享静态成员 |
| 02_student | 学生编号与累计人数 |
| 03_static_function | 静态函数访问规则及订正 |
| 5-3_scope | 全局与局部变量 |
| 5-7_cat | 存活对象计数、拷贝与析构 |
| 5-13_friend | 友元成员函数、友元类与友元函数 |

也可在 week3 目录的终端执行 `bash run.sh 5-7_cat`，替换最后的题目目录名即可。编译结果在 build 中，已排除出 Git 提交。

## 断点调试

编译后，在终端输入 `lldb build/5-7_cat`，依次输入 `breakpoint set --name 'Cat::~Cat()'` 和 `run`；使用 `next` 单步执行、`frame variable` 观察局部变量、`continue` 继续、`quit` 退出。其他练习可按报告中的断点位置调整。
