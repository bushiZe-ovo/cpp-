# 实验二 C++简单程序设计

本实验包含课件补充2-1至2-14，以及8道控制结构编程题。每个 .cpp 文件均是独立程序，必须单独编译，不要把多个含 main 的文件一起编译。

## 文件说明

- `实验02_C++简单程序设计实验报告.docx`：按课程模板填写的报告，个人信息和真实 GitHub 链接需补全。
- `src/basics/`：14个基础类型及运算符练习。
- `src/tasks/`：8道编程题。
- `results/`：实际运行输入与输出；`images/` 为输出文本生成的结果图，并非课堂电脑的界面截图。
- `results/verification.txt`：39项检查的记录。

## 编程题设计

| 文件 | 题目 | 设计方法 | 样例结果 |
|---|---|---|---|
| 01_bonus.cpp | 奖金计算 | 六档累进、if/else | 利润1200000元，奖金41500元 |
| 02_movie.cpp | 电影评分 | 从高到低判断区间 | 7分：非常好 |
| 03_palindrome.cpp | 回文数 | 取余、整除、反转 | 12321：回文 |
| 04_armstrong.cpp | 水仙花数 | 拆位、遍历三位数 | 153 370 371 407 |
| 05_series.cpp | 重复数字数列 | term=term*10+a，逐项累加 | n=3,a=2：246 |
| 06_table.cpp | 九九乘法表 | 双重循环 | 9行45项 |
| 07_rabbits.cpp | 兔子问题 | 循环递推、临时变量保存旧值 | 第20月6765对、13530只 |
| 08_peaches.cpp | 猴子吃桃 | 从第10天向前逆推9次 | 1534个 |

兔子题按订正要求：出生后的第1、2个月不生育，第3个月起每月生一对。设第n个月为F(n)对，则F(1)=F(2)=1，F(n)=F(n-1)+F(n-2)。`previous` 和 `current` 保存前两个月，先求 `next`，再依次更新。程序仅在 `main` 内使用循环，不使用自定义求解函数或递归。输出只数为对数的2倍。

电影评分按0～10整数输入；数列中的a为1～9的一位正整数，n为正整数，超过long long表示范围会提示Overflow；回文数输入为int，负数不计为回文数，0计为回文数。

## 编译运行

验证环境：macOS、Apple Clang 17.0.0、C++17。22个程序已独立编译运行，核心题目完成39项结果检查。

以兔子问题为例：

```sh
clang++ -std=c++17 -Wall -Wextra src/tasks/07_rabbits.cpp -o rabbits
./rabbits
```

也可使用 `g++ -std=c++17`。在 Visual Studio 中为每个题目建立独立控制台项目，只加入对应源文件，选择C++17；中文源文件使用UTF-8，必要时启用 `/utf-8`。

## 基础实验说明

基础练习按照课件代码整理。2-10的连续自增自减输出拆为独立语句，便于逐步观察；后置++优先级高于一元负号。`sizeof(long)`、`sizeof(long double)`及整数边界以实际平台为准，本环境long和long double均为8字节。2-4中超范围的有符号转换在C++17下属于实现定义行为，本环境结果为-15536。2-8包含退格和响铃控制字符，其显示效果取决于终端。
